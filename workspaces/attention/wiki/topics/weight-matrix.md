A [[weight matrix]] is a fundamental component in neural networks, used to transform input data and learn relationships between features. In [[Recurrent Neural Network (RNN)|RNN]]s, weight matrices ($W_{hh}$, $W_{xh}$) are shared across [[time step|time steps]] for updating the [[hidden state]]. In [[Self-attention]], learned weight matrices are used to transform token [[embedding]]s into [[Query (Q)|Query]], [[Key (K)|Key]], and [[Value (V)|Value]] vectors.
