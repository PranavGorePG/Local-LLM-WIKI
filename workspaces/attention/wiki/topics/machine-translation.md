[[Machine Translation]] is a sub-field of computational linguistics that investigates the use of software to translate text or speech from one natural language to another. Historically, rule-based and statistical methods were dominant. However, with advancements in deep learning, neural machine translation (NMT) models have become state-of-the-art. These models, often employing [[Encoder-Decoder Architecture]]s, learn to map input sequences in a source language to output sequences in a target language. The quality of machine translation is frequently evaluated using metrics such as the [[BLEU Score]].Innovations in architectures like [[Recurrent Neural Networks (RNNs)]] and [[Convolutional Neural Networks (CNNs)]], and especially [[Attention Mechanism]]s, have significantly improved translation quality. A major breakthrough came with the introduction of the [[Transformer Architecture]] in "[[Attention Is All You Need]]" (Vaswani et al., 2017), which achieved new state-of-the-art results by relying solely on attention, demonstrating superior parallelization and efficiency. This work established a new paradigm for machine translation models and subsequent [[Large Language Models (LLMs)]].
