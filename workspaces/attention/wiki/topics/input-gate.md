The [[input gate]] is one of the gating mechanisms in a [[Long Short-Term Memory (LSTM)]] cell. It controls which values from the current input and [[hidden state]] are used to update the [[cell state]]. Along with the [[forget gate]] and [[output gate]], it helps regulate the flow of information within the LSTM to capture relevant context and mitigate the [[vanishing gradient problem]].
