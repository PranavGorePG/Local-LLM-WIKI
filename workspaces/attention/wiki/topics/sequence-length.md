[[Sequence length]] refers to the number of elements in an ordered sequence. This is a critical factor affecting the performance and computational cost of sequence modeling algorithms. For example, [[Self-attention]] exhibits [[quadratic complexity]] with respect to sequence length, while [[Recurrent Neural Network (RNN)|RNN]]s have linear complexity.
