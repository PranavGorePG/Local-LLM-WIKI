A [[Seq2Seq model]] (Sequence-to-Sequence model) is an architecture designed to transform an input sequence into an output sequence, where the lengths of the input and output sequences can differ. Typically composed of an [[Encoder-decoder architecture|encoder]] and a [[Encoder-decoder architecture|decoder]], Seq2Seq models were initially popular using [[Recurrent Neural Network (RNN|RNN]]s. [[Transformer architecture|Transformers]] have largely superseded RNN-based Seq2Seq models for tasks like [[Machine Translation]] and [[Text generation]].
