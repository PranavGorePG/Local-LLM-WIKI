The [[Transformer architecture]], introduced in "Attention Is All You Need," is a model architecture that relies heavily on [[Self-attention]] mechanisms. It eliminated the need for [[Recurrent Neural Network (RNN)|RNN]]s in many sequence modeling tasks by enabling parallel processing of input sequences and effectively capturing [[long-range dependency|long-range dependencies]]. Key components include multi-head attention and positional encodings.
